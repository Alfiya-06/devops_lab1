# Лабораторная работа П01: Базовое администрирование Linux и вход по SSH

**Выполнила:** Аптракова Альфия, студентка группы ИТ-1

**Среда выполнения:** WSL2 (Ubuntu 24.04 LTS на базе Windows)

## Описание

1. Системная (`uname`, `lsb_release`, `top`) и сетевая диагностика.
2. Создание пользователя `devuser` с домашним каталогом и оболочкой Bash.
3. Настройка прав `sudo` без ввода пароля (`NOPASSWD`).
4. Генерация SSH-ключей и настройка авторизации по ключу (`authorized_keys`).
5. Подключение к виртуальной среде Linux из VS Code через расширение Remote - SSH.
